最終更新2026-08-26

4大機能 + 2つのユニーク機能

📅 期限管理・進捗追跡

  • 課題の CRUD（作成/読取/更新/削除）
  • ステータス: 未着手 / 進行中 / 完了
  • 優先度: 低 / 中 / 高
  • 教科分類、期限日時、詳細説明

📆 カレンダー表示

  • 月間カレンダー（モバイル対応）
  • 色分け: 期限切れ(赤) / 今日(青) / 近い(黄) / 未来(緑)
  • 日付クリックで課題一覧表示

👥 グループ共有

  • グループ作成 / 招待コード生成（8文字）
  • 招待コードで参加
  • 権限: 管理者(編集可) / メンバー(閲覧のみ)
  • メンバー進捗確認

🔔 通知リマインダー

  • Vercel Cron（毎日午前9時実行）
  • 期限通知: 3日前 / 前日 / 当日 / 期限切れ
  • ブラウザ通知 API 対応
  • 既読/未読管理、フィルタ機能

🆕 ユニーク機能（コンテスト差別化ポイント）

📝 自然言語課題入力 NEW

  • NVIDIA Build API (GPT-OSS-120B) 使用 - 永久無料・OpenAI互換
  • 日本語自然文から構造化データ抽出
  • 対応パターン: 「明日」「明後日」「来週金曜日」「3日後」「9/15」「9月15日」等
  • 教科辞書: 数学/英語/国語/理科/社会/情報 + 詳細教科（物理/化学/世界史等）
  • 正規表現パーサーをフォールバックとして実装（LLM失敗時自動切替）
  • UI: タブ切替（手動/自然言語）、解析結果プレビューカード、5状態ステートマシン
  • 既存 API (`POST /api/assignments`) 変更なしで統合

🧠 認知負荷適応スケジューラ NEW

  • 5ヒューリスティック加重スコアリング:
    • 締切圧力: 40%
    • 認知負荷（教科別）: 20%
    • 完了履歴・遅延率: 15%
    • 教科多様性（クラスタリング防止）: 10%
    • 期限超過自動優先: 15%
  • `assignments.completedAt` を活用した遅延パターン分析
  • 教科ごとの認知負荷定数（数学=8, 物理=9, 英語=6 等）
  • Server Action: `getScheduledTasks()` で全課題+履歴を取得・スコアリング・ランキング
  • LLM API Route: パーソナライズド学習推奨（順序・理由・ポモドーロ計画）
  • UI: ScheduleWidget（順位番号・スコアバー・残り時間・優先度バッジ・ポモドーロ表示）
  • ダッシュボード統計カード下部に配置

git add -A && git commit -m "feat: ..." && git push origin main

vercel --prod --yes
